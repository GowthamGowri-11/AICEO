The attention mechanism projects inputs into three separate representation spaces termed queries, keys, and values.

A subset is a set whose elements are all fully contained within another larger superset.
A function maps every element from a source domain set to a single corresponding element in a target codomain set.
An injective function maps distinct source elements to strictly distinct target codomain elements.
A surjective function ensures that every element in the target codomain is mapped to by at least one domain element.
A bijective function is simultaneously injective and surjective, establishing a perfect one-to-one correspondence.
Linear independence ensures that no vector in a set can be written as a linear combination of the remaining vectors.
The span of a set of vectors is the subspace containing all possible linear combinations of those vectors.
A basis of a vector space is a linearly independent set of vectors whose mathematical span encompasses the entire space.
The dimension of a vector space is defined as the total number of vectors comprising any basis for that space.
Matrix transpose swaps rows and columns such that the element at row i column j moves to row j column i.
A symmetric matrix is equal to its own transpose, satisfying the property that A equals A transpose.
An orthogonal matrix is a square real matrix whose columns and rows are mutually orthogonal unit vectors.
Singular Value Decomposition factors any real matrix into the product of two orthogonal matrices and a diagonal matrix.
SVD is widely used in signal processing, image compression, noise reduction, and recommendation engines.
Limits describe the behavior of a mathematical function as the independent variable approaches a specific value.
A function is continuous if small changes in the input produce arbitrarily small changes in the output.
Partial derivatives evaluate the instantaneous rate of change of a multivariable function along a single coordinate axis.
The gradient vector points in the direction of greatest rate of increase of a scalar multivariable function.
The Hessian matrix contains all second-order partial derivatives, characterizing the local curvature of a function.
Convex functions have the property that line segments connecting any two points on their graph lie above the curve.
Global minima of convex optimization functions can be found reliably because local minima are always global minima.
Graph coloring assigns labels called colors to graph vertices such that no adjacent vertices share the same color.
A planar graph is a graph that can be drawn on a two-dimensional plane without any intersecting edges.
Euler formula establishes that for any connected planar graph, vertices minus edges plus faces equals two.
A tree is an undirected connected graph containing no closed cycles or loops.
A spanning tree of a connected graph is a subgraph that is a tree containing all vertices of the original graph.
Kruskal algorithm finds a minimum spanning tree by greedily adding the cheapest valid edges that do not form cycles.
Prim algorithm constructs a minimum spanning tree by growing a tree from an initial vertex one edge at a time.
Topological sorting arranges the vertices of a directed acyclic graph in a linear order consistent with edge directions.
Shortest path algorithms calculate the minimal cost path connecting a source vertex to a destination vertex.
A priority queue is an abstract data structure where elements are served based on assigned numerical priority.
Binary heaps implement priority queues efficiently, providing logarithmic insertion and extraction operations.
Amortized analysis averages the running time of operations across an extended sequence of computational actions.
Trie data structures store associative keys by branching on consecutive characters, enabling fast prefix lookups.
Bloom filters are space-efficient probabilistic data structures used to test set membership with zero false negatives.
Bitwise operations manipulate individual binary bits directly, enabling high-performance low-level computations.
Integer overflow occurs when an arithmetic calculation exceeds the maximum numeric value representable by a data type.
Floating point representation approximates real numbers using fixed-size mantissa and exponent binary fields.
Cell division occurs through mitosis for somatic tissue growth and meiosis for producing haploid gametes.
Mitosis duplicates chromosomes and divides them equally, producing two genetically identical diploid daughter cells.
Meiosis involves two sequential nuclear divisions, resulting in four genetically distinct haploid reproductive cells.
Crossing over during meiosis exchanges genetic material between homologous chromosomes, promoting genetic diversity.
Mendel discovered the basic laws of inheritance by cross-breeding garden pea plants with contrasting traits.
The law of segregation states that alleles for a gene separate during gamete formation so each gamete carries one allele.
The law of independent assortment dictates that genes for different traits segregate independently during gamete production.
Genotype represents the complete set of hereditary genes carried by an organism within its genome.
Phenotype represents the observable physical, physiological, and behavioral characteristics of an organism.
Dominant alleles mask the phenotypic expression of recessive alleles in heterozygous individuals.
Homozygous individuals carry two identical alleles for a given gene locus on homologous chromosomes.
Heterozygous individuals carry two different alleles for a specific gene locus on homologous chromosomes.
Gene expression involves transcription of DNA into messenger RNA followed by translation into functional proteins.
Transcription takes place inside the cell nucleus, where RNA polymerase synthesizes mRNA from a DNA template strand.
Translation takes place in the cytoplasm, where ribosomes synthesize proteins using aminoacyl-transfer RNA molecules.
Codons are triplets of nucleotide bases in messenger RNA that specify particular amino acids during translation.
The genetic code is degenerate because multiple distinct three-base codons can encode the exact same amino acid.
Mutations are changes in the nucleotide sequence of DNA caused by replication errors or environmental mutagens.
Point mutations alter a single nucleotide base pair, categorized as silent, missense, or nonsense mutations.
Frameshift mutations insert or delete nucleotides in numbers not divisible by three, disrupting downstream codons.
Epigenetic modifications alter gene expression patterns without modifying the underlying DNA nucleotide sequence.
DNA methylation and histone acetylation are major epigenetic mechanisms that regulate chromatin accessibility.
Homeostasis is the biological process through which organisms maintain stable internal physiological conditions.
Negative feedback mechanisms counteract deviations from physiological set points to preserve stable balance.
Hormones are chemical signaling molecules transported through the bloodstream to regulate distant target organs.
The nervous system transmits rapid electrical impulses through interconnected networks of neurons and synapses.
Action potentials are rapid, transient reversals of electrical membrane potential propagating along neuronal axons.
Neurotransmitters are chemical ligands released across synaptic junctions to transmit signals between neurons.
Synaptic plasticity refers to the biological capacity of synapses to strengthen or weaken over time in response to activity.
Long-term potentiation is a persistent strengthening of synapses based on recent patterns of correlated activity.
Neuroplasticity underlies the biological capacity of the brain to learn new skills and recover from localized injury.
Immune systems defend organisms against invading pathogenic viruses, bacteria, protozoa, and parasitic worms.
Innate immunity provides non-specific physical, chemical, and cellular defense mechanisms active from birth.
Adaptive immunity generates antigen-specific immunological memory through specialized B-lymphocytes and T-lymphocytes.
Antibodies are Y-shaped immunoglobulins produced by plasma cells that neutralize antigens and tag them for destruction.
Vaccines stimulate adaptive immunity by exposing the immune system to harmless antigen fragments of pathogens.
Herd immunity occurs when a sufficiently large proportion of a population is immune, protecting vulnerable individuals.
Antibiotic resistance evolves when bacterial populations undergo natural selection in the presence of antimicrobial drugs.
Gram-positive bacteria have thick peptidoglycan cell walls, whereas Gram-negative bacteria possess outer lipid membranes.
Viruses are obligate intracellular parasitic agents consisting of genetic material enclosed within a protein capsid.
Linguistic typology classifies world languages according to their structural, grammatical, and morphological features.
Subject-Verb-Object and Subject-Object-Verb are the two most prevalent canonical word order topologies across languages.
Agglutinative languages build complex words by concatenating distinct, easily separable morphemes with discrete meanings.
Isolating languages maintain low morpheme-to-word ratios, relying on word order and auxiliary particles for grammar.
Inflected languages modify root words using multifaceted affixes that simultaneously encode tense, case, and number.
Lexical categories encompass major open word classes including nouns, verbs, adjectives, and adverbs.
Functional categories encompass closed grammatical word classes such as determiners, pronouns, prepositions, and conjunctions.
Constituency tests evaluate whether a group of adjacent words functions as a unified syntactic phrase in a sentence.
Phrase structure grammars generate syntactic trees illustrating the hierarchical nesting of grammatical constituents.
Universal grammar posits that humans possess an innate cognitive capacity for acquiring natural language syntax.
